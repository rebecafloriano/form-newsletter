# 📧 Modern Newsletter Subscription Form

A professional, accessible, and responsive newsletter subscription form built with **React**, **TypeScript**, and **Tailwind CSS**.
![Project Screenshot](./assets/screenshot.png)

> 🚀 **Live Demo:** [https://rebecafloriano.github.io/form-newsletter/](https://rebecafloriano.github.io/form-newsletter/)

## ✨ Key Features
*   **Custom Validation**: Real-time validation for user data and terms of service.
*   **Accessibility (A11y)**: Built with semantic HTML and ARIA standards for screen readers.
*   **API Integration**: Simulated POST requests with loading, success, and error states.
*   **Clean Architecture**: Separation of concerns between UI components, business logic, and types.

## 🛠️ Tech Stack
*   **React 19**
*   **TypeScript** (Strict Mode)
*   **Tailwind CSS**
*   **Vite**

## 📂 Project Structure
*   `src/components/ui`: Atomic UI components (Input, Button, Checkbox).
*   `src/utils`: Validation logic and helper functions.
*   `src/types`: TypeScript interfaces.
