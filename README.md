# 📧 Modern Newsletter Subscription Form

A professional, accessible, and responsive newsletter subscription form built with **React**, **TypeScript**, and **Tailwind CSS**.

![Project Screenshot](./src/assets/screenshot.png)

> 🚀 **Live Demo:**  
> https://rebecafloriano.github.io/form-newsletter/

---

## ✨ Key Features

- **Custom Validation**  
  Real-time validation for user data and terms of service.

- **Accessibility (A11y)**  
  Built with semantic HTML and ARIA standards for screen readers.

- **API Integration**  
  Simulated POST requests with loading, success, and error states.

- **Clean Architecture**  
  Separation of concerns between UI components, business logic, and types.

---

## 🛠️ Tech Stack

- **React 19**
- **TypeScript** (Strict Mode)
- **Tailwind CSS**
- **Vite**

## 🚀 How to Run the Project

Follow these steps to run the project locally:

### 1. Clone the repository
```bash
git clone https://github.com/rebecafloriano/form-newsletter.git
```

### 2. Navigate to the project folder
```bash
cd form-newsletter
```

### 3. Install dependencies
```bash
npm install
```

### 4. Start the development server
```bash
npm run dev
```

### 5. Open in your browser
```
http://localhost:5173
```

## 📂 Project Structure

- `src/components/ui` → Atomic UI components (Input, Button, Checkbox)  
- `src/utils` → Validation logic and helper functions  
- `src/types` → TypeScript interfaces
